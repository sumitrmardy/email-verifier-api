# assets

`social-preview.png` goes here: 1280×640, set in GitHub under
**Settings → General → Social preview**.

It does not exist yet. No image could be generated while this repo was built,
and a placeholder would be worse than none — GitHub falls back to the owner's
avatar, which at least looks deliberate.

What it should carry, readable in one glance at thumbnail size:

- the name
- `SMTP · MX · Catch-all · Disposable`
- `n8n · MCP · OpenAPI`
- one line of Chinese: 批量邮箱验证

Large type, high contrast, no paragraph anyone has to squint at. It is read at
the size of a chat thumbnail, not a monitor — which is the whole reason it
exists, since a link shared in Slack or a forum shows this and nothing else.
